# Amazon-Sales-Sample-PowerBI-Dashboard
Interactive Power BI dashboard analyzing Amazon sales sample data.

This project is an interactive Power BI dashboard built using a sample Amazon sales dataset.  
The objective of this project is to analyze sales performance, profitability, returns, and regional trends using business-focused visualizations.

> Note: This project uses a publicly available sample dataset and is created for learning and portfolio purposes.

---

## 📊 Dashboard Features

### 🔹 Sales Analysis
- Sales by Segment (donut chart)
- Sales by Payment mode (donut chart)
- Sales by Ship (donut chart)
- Sales per year wise trend analysis

### 🔹 Profit Analysis
- Sales vs Profit per Quarter comparison
- Top 3 Sub-Categories based on Profit

### 🔹 Returns Analysis
- Return vs Non-Return analysis using a calculated column
- Pie chart visualization for return distribution

### 🔹 Regional Analysis
- Interactive State-level filtering using slicers
- Region-wise filtering for comparative analysis
- Map visualization showing sales distribution across states

---

## 🛠 Tools & Technologies Used
- Power BI
- Data visualization and dashboard design
- Filters and slicers
- Basic DAX (calculated columns)
- Data cleaning and transformation

---

## 🎯 Project Objective
To practice real-world business analysis by converting raw sales data into meaningful insights through an interactive and user-friendly Power BI dashboard.
